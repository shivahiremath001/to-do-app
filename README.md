# To-Do App 📝

A lightweight, fully functional To-Do application built with vanilla web technologies. It features persistent local storage, smart state management, and a clean, responsive UI with interactive hover effects.

**[View Live Demo](https://shivahiremath001.github.io/to-do-app/)**

## ✨ Features

* **Persistent Storage:** Tasks are saved in the browser's `localStorage`, meaning you won't lose your data if you refresh or close the tab.
* **Smart Sorting:** Checking a task off automatically marks it as complete, strikes through the text, and moves it to the bottom of the list.
* **Task Deletion:** A "Remove" (X) button dynamically appears on completed tasks, allowing you to keep your list clean.
* **Duplicate Prevention:** The app automatically checks for and prevents you from adding duplicate tasks (case-insensitive).
* **Hover Timestamps:** Every task records the exact date and time it was created. To keep the UI clean, this information is hidden and smoothly transitions into view only when you hover over the task.

## 🛠️ Technologies Used

* **HTML5:** Semantic structure.
* **CSS3:** Flexbox layout, dynamic classes, and transition animations.
* **JavaScript (ES6+):** Object-oriented component generation, DOM manipulation, array filtering, and JSON data serialization.
